# 周评展示模板

周评沿用日评页面，只更换期间和数据基准，不另做复杂页面。

```text
〔本周情景标题〕
统计期间：〔起止日期〕
比较基准：〔上周最后有效交易日〕

〔指标1本周变化〕  〔指标2本周变化〕

本周发生了什么
〔用1—2句话描述主线和分化，不拼接五篇日评〕

可能有什么影响
〔描述组合影响条件，区分存量估值与再投资〕

沟通参考
〔解释周度变化，不能将一天表现当成一周表现〕

下周关注：〔1—2项可核实事项〕
来源、版本及审核状态
```

指数周涨跌＝本期最后有效收盘÷上期最后有效收盘−1。收益率及利差变化用BP。不同市场分别处理交易日历与截止时点。不得简单相加日涨跌幅，也不能以固定周五假定各市场均开市。

触发场景按周度统计值判断，不能把日内阈值直接用于周评。同一事件仍需标明具体发布日期，不能无证据地归因一周行情。
