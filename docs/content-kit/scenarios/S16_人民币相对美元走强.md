# S16 人民币相对美元走强

版本：1.0｜状态：内部模板草案，待机构审核｜关注级别：常规

## 何时使用

统一为每美元兑人民币报价；该报价下降表示人民币相对美元走强。

只描述已核实变化。阈值由机构按指标、期间、历史波动与使用目的配置；本模板不默认设置统一数值门槛。

## 必需数据与证据

| 业务字段 | 含义 |
|---|---|
| `as_of` | 数据截至时间 |
| `benchmark` | 比较基准 |
| `fx_market` | 在岸/离岸市场 |
| `fx_pair` | 汇率报价方向 |
| `fx_value` | 汇率水平 |
| `fx_change_pct` | 汇率报价有符号涨跌幅(%) |

Wind指标、数据时点与同口径基准；事件另附正式原文；产品信息以管理人或销售机构正式披露为依据。

## 展示模板

**日评标题：**人民币相对美元走强

**周评标题：**本周市场：人民币相对美元走强

**异动标题：**人民币相对美元走强

**发生了什么**

截至〔数据时点〕，〔在岸/离岸〕美元兑人民币报价为〔汇率水平〕，较〔比较基准〕下降〔变动幅度〕%，人民币相对美元走强。

**可能有什么影响**

未对冲的美元资产人民币折算价值可能受影响；实际产品表现还取决于资产价格、币种及对冲安排。

**沟通参考（内部草案）**

人民币升值对不同产品的影响有差异。需要看产品是否有美元敞口及对冲安排，而不能只凭汇率涨跌判断。

**接下来关注**

避免混用中间价、在岸价、离岸价及不同时间点。



## 原因如何表述

原因尚待进一步核实。只有获得可追溯证据后，才补充经核实的解释。

如需说明原因，单独记录证据、日期和链接；相关性不等于因果，不根据Wind价格变化自动生成确定归因。

## 本情景需避免的写法

不得写“外币产品都会亏损”“现在应全部换回人民币”。

## 发布与消保要求

- 核对字段完整、日期与单位、比较基准、方向和来源，不将指数幅度套用到产品净值。
- 风险和限制与“可能影响”同屏，保留客户自主选择；不作统一加仓、赎回或换仓指令。
- 不预测单只产品收益，不承诺本金、收益、回本时间或限定损失。
- 内部内容及对客内容分别审核；任何数值、原因或结论变更须重新复核。
- 产品风险或重大事项按机构流程提供正式查询、反馈渠道；具体产品推介另走销售和适当性流程。
- 数据/证据不足时使用S29；发布后更正使用S30。
