# S20 海外债券收益率下行

版本：1.0｜状态：内部模板草案，待机构审核｜关注级别：常规

## 何时使用

指定国家、期限和来源的收益率下行，标注当地时点。

只描述已核实变化。阈值由机构按指标、期间、历史波动与使用目的配置；本模板不默认设置统一数值门槛。

## 必需数据与证据

| 业务字段 | 含义 |
|---|---|
| `as_of` | 数据截至时间 |
| `local_trade_date` | 当地交易日 |
| `local_as_of` | 当地数据时点 |
| `local_timezone` | 当地时区或UTC偏移 |
| `benchmark` | 比较基准 |
| `foreign_yield_name` | 海外国家/期限收益率 |
| `foreign_yield_pct` | 海外收益率水平(%) |
| `foreign_yield_change_bp` | 海外收益率有符号变动(BP) |

Wind指标、数据时点与同口径基准；事件另附正式原文；产品信息以管理人或销售机构正式披露为依据。

## 展示模板

**日评标题：**海外债券收益率下行

**周评标题：**本周市场：海外债券收益率下行

**异动标题：**海外债券收益率下行

**发生了什么**

截至〔当地数据时点〕（〔当地时区〕），〔海外收益率指标〕为〔收益率水平〕%，较〔比较基准〕下行〔下行幅度〕个基点。

**可能有什么影响**

相关存量债券估值可能改善，再投资条件也可能改变。币种、期限及对冲会影响组合结果。

**沟通参考（内部草案）**

利率下降对存量资产和未来再投资的作用不同，不能直接推导某只产品的未来回报。

**接下来关注**

关注久期、汇率、再投资条件和实际政策。



## 原因如何表述

原因尚待进一步核实。只有获得可追溯证据后，才补充经核实的解释。

如需说明原因，单独记录证据、日期和链接；相关性不等于因果，不根据Wind价格变化自动生成确定归因。

## 本情景需避免的写法

不得写“降息必然利好所有资产”“未来收益确定”。

## 发布与消保要求

- 核对字段完整、日期与单位、比较基准、方向和来源，不将指数幅度套用到产品净值。
- 风险和限制与“可能影响”同屏，保留客户自主选择；不作统一加仓、赎回或换仓指令。
- 不预测单只产品收益，不承诺本金、收益、回本时间或限定损失。
- 内部内容及对客内容分别审核；任何数值、原因或结论变更须重新复核。
- 产品风险或重大事项按机构流程提供正式查询、反馈渠道；具体产品推介另走销售和适当性流程。
- 数据/证据不足时使用S29；发布后更正使用S30。

## 统一尾注

数据截至〔数据时点〕。市场数据来源：Wind〔指标口径〕；事件及产品信息来源：〔正式披露链接〕。市场指标不等于具体理财产品表现，实际影响需结合产品持仓、估值及管理人披露判断。本文供内部参考，涉及客户沟通须使用本机构审核内容。

## 维护方式

本文件与scenarios.json中的S20对应。结构字段固定，填充数字不需要改小程序页面；内容审核通过后绑定数据快照和版本发布。对客材料的权限与发布状态应由服务端控制。
