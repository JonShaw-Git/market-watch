# S12 权益结构分化

版本：1.0｜状态：内部模板草案，待机构审核｜关注级别：常规

## 何时使用

不同指数、行业或风格表现差异达到机构设定条件。

只描述已核实变化。阈值由机构按指标、期间、历史波动与使用目的配置；本模板不默认设置统一数值门槛。

## 必需数据与证据

| 业务字段 | 含义 |
|---|---|
| `as_of` | 数据截至时间 |
| `benchmark` | 比较基准 |
| `equity_group_a` | 指数/行业A |
| `equity_return_a_pct` | A有符号涨跌幅(%) |
| `equity_group_b` | 指数/行业B |
| `equity_return_b_pct` | B有符号涨跌幅(%) |
| `period` | 统计期间 |

Wind指标、数据时点与同口径基准；事件另附正式原文；产品信息以管理人或销售机构正式披露为依据。

## 展示模板

**日评标题：**权益结构分化

**周评标题：**本周市场：权益结构分化

**异动标题：**权益结构分化

**发生了什么**

〔期间〕，〔指数/行业A〕变动〔A涨跌幅〕%，〔指数/行业B〕变动〔B涨跌幅〕%，表现分化。

**可能有什么影响**

不同投资范围和风格敞口可能导致产品表现不同。热门板块表现不能替代组合整体表现。

**沟通参考（内部草案）**

本期不同板块走势有差异，理解产品实际投资范围，比只看当天热门板块更有助于解释净值。

**接下来关注**

核对行业权重、投资范围及数据样本。



## 原因如何表述

原因尚待进一步核实。只有获得可追溯证据后，才补充经核实的解释。

如需说明原因，单独记录证据、日期和链接；相关性不等于因果，不根据Wind价格变化自动生成确定归因。

## 本情景需避免的写法

不得写“下一轮一定轮到某板块”，不得诱导频繁换仓。

## 发布与消保要求

- 核对字段完整、日期与单位、比较基准、方向和来源，不将指数幅度套用到产品净值。
- 风险和限制与“可能影响”同屏，保留客户自主选择；不作统一加仓、赎回或换仓指令。
- 不预测单只产品收益，不承诺本金、收益、回本时间或限定损失。
- 内部内容及对客内容分别审核；任何数值、原因或结论变更须重新复核。
- 产品风险或重大事项按机构流程提供正式查询、反馈渠道；具体产品推介另走销售和适当性流程。
- 数据/证据不足时使用S29；发布后更正使用S30。

## 统一尾注

数据截至〔数据时点〕。市场数据来源：Wind〔指标口径〕；事件及产品信息来源：〔正式披露链接〕。市场指标不等于具体理财产品表现，实际影响需结合产品持仓、估值及管理人披露判断。本文供内部参考，涉及客户沟通须使用本机构审核内容。

## 维护方式

本文件与scenarios.json中的S12对应。结构字段固定，填充数字不需要改小程序页面；内容审核通过后绑定数据快照和版本发布。对客材料的权限与发布状态应由服务端控制。
