# 异动点评展示模板

建议150—250字，首屏回答“发生什么、可能影响、如何解释”。

```text
〔情景标题〕
截至〔时点〕 · 首评/更新/更正 · 内部草案/已审

〔核心指标〕：〔值〕；较〔基准〕变动〔幅度〕

发生了什么
〔已核实事实〕。

可能有什么影响
〔传导机制、实际敞口限制和风险〕。

沟通参考
〔针对本事件的通俗解释，不预测回本或收益〕。

关注：〔下一项待核实信息〕
[展开来源及更新记录]
```

阈值触发只生成待核实事件。信用事件、产品净值及突发消息分别需要对应正式披露，不能从价格变化自动推断。多情景合并时保留一个主情景，避免重复发布。原因未确认就不写确定因果。
