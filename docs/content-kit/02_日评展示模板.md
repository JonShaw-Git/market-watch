# 日评展示模板

建议正文180—300字；优先展示2—3项与本篇直接相关的数据。

```text
看市场
[市场解读]  [研报观点]  [异动点评]
每日 / 每周

〔情景标题〕                  内部草案/已审
截至〔数据时点〕 · 市场数据来源Wind

〔指标1：值/变动〕  〔指标2：值/变动〕

发生了什么
〔事实句：指标、期间、比较基准、幅度〕

可能有什么影响
〔传导机制＋持仓等条件＋相关风险〕

沟通参考
〔通俗解释；不给统一交易指令，不承诺收益〕

关注：〔需要核实的下一项信息〕
[展开数据与来源]
[复制内部草稿 / 使用已审客户版本]
```

情景正文从S01—S30选择。市场原因不是必填项，证据不足时不作确定解释。正文及数字共同绑定同一快照；风险与影响放在一起。
