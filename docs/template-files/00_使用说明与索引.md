## 更新方式

1. 沿用机构已有Wind表服务填充〔字段〕，记录指标、口径、时点、基准、来源与提取时间。
2. 依据情景条件匹配模板；方向与原因分别核实；多情景共同发生时人工合并。
3. 日评与周评使用独立区间，周收益不累加日涨跌；研报核实原文和授权；异动规则由机构配置。
4. 业务、合规、消保依机构制度完成审核；产品与未确认信息默认内部使用。
5. 发布保存数据快照、文案、审核记录和版本；数据更正醒目标识并重新审核。
